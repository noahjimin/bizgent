### 한 줄 소개

소상공인 사장님이 매장·상품 정보와 마케팅 목표를 입력하면, AI가 타겟층 고객과 홍보·캠페인 방향을 분석해 광고 이미지·홍보 문구·게시물 등 콘텐츠 시안을 자동으로 생성하여 추천 해주는 AI 디지털 마케팅 에이전트입니다. 게시 이후에는 매장 매출 데이터를 바탕으로 캠페인 성과를 분석하고, 잘된 캠페인과 아쉬운 캠페인을 비교해 다음 캠페인의 개선 방향까지 제안합니다.

## 2. 프로젝트 배경 및 목적

### 2.1 해결하려는 문제

소상공인은 전문 마케팅 인력을 별도로 두기 어려워 SNS·블로그 등 디지털 채널을 활용한 홍보를 직접 수행하는 경우가 어려우며 타겟 고객 설정, 캠페인 기획, 광고 문구·이미지 제작, 채널별 콘텐츠 구성과 게시까지 지속적으로 수행하기에는 시간과 전문성이 부족합니다. 또한 홍보를 진행하고도 실제 매출에 어떤 영향을 주었는지 확인하고 다음 홍보에 반영하기가 어렵습니다. 본 프로젝트는 매장·상품 정보와 마케팅 목표만 입력하면 AI가 타겟 고객과 캠페인 방향을 분석하고, 선택한 채널에 맞는 시안까지 생성해주며, 게시 이후 매출 데이터를 바탕으로 개선 방향까지 제안하는 시스템을 개발합니다.

### 2.2 프로젝트 목적

매장·상품·서비스 정보와 마케팅 목표 입력 → AI 캠페인 기획(타겟 고객·방향 분석) → 콘텐츠 시안(이미지·문구·게시물) 생성 → 비교·수정·선택 → 게시 → 매출 데이터 입력 → 매출 기반 성과 분석 → AI 캠페인 개선 방향 제안 → 다음 캠페인 개선으로 이어지는 흐름을 하나의 플랫폼에서 제공하여, 소상공인이 마케팅 전문 인력 없이도 홍보를 기획·제작·게시·개선할 수 있도록 지원합니다.

### 2.3 기대효과

- 마케팅 목표만 입력하면 AI가 타겟 고객 분석부터 캠페인 전략까지 제안해, 전문 인력 없이도 체계적인 홍보를 진행할 수 있습니다.
- 광고 이미지·홍보 문구·게시물 등 다양한 콘텐츠 시안을 한 번에 받아보고 비교·선택할 수 있어 콘텐츠 제작 시간을 크게 줄일 수 있습니다.
- 게시할 채널(인스타그램, 카카오톡 채널, 블로그, 당근마켓 등)을 선택하면 채널 특성에 맞는 콘텐츠로 생성되어 바로 활용할 수 있습니다.
- 매출 데이터를 바탕으로 캠페인의 효과를 확인하고, 잘된 캠페인과 아쉬운 캠페인의 비교를 통해 다음 캠페인을 개선할 수 있어 지속적으로 마케팅 성과를 높일 수 있습니다.
- 비인기 메뉴 조언, 재고 소진 프로모션 제안 등 매장 운영에 직접 도움이 되는 제안을 받을 수 있습니다.

## 4. 핵심 서비스 시나리오

### 캠페인 기획·콘텐츠 생성 시나리오

캠페인 생성은 6개 노드의 위자드(1 목표 설정 → 2 AI 기획 → 3-1 콘텐츠 설정 → 3-2 이미지 설정 → 4 시안 비교 → 5 게시)로 진행됩니다.

> 단계 이동 정책: 캠페인 생성 중에는 이전 단계로 돌아갈 수 없습니다(이전 버튼 없음). "다음"을 누르면 "다음 단계로 넘어가면 지금 단계의 내용은 다시 수정할 수 없어요" 확인 팝업이 표시되고, 확인 시에만 다음 단계로 이동합니다. 크레딧 낭비와 사용자 혼란을 막기 위한 설계이며, 대신 2단계부터 4단계까지 오른쪽 고정 패널("확정된 캠페인 내용")에 앞 단계에서 확정한 목표·캠페인 방향·타겟 고객·전략·기대효과를 계속 보여줍니다. 캠페인 생성 화면에서는 왼쪽 사이드바를 숨기고 단계 진행에만 집중하도록 구성합니다.

1. 사장님이 랜딩 페이지에서 "무료로 시작하기" 또는 "매장 대표 이미지 무료 생성하기"를 누르면 이용약관 동의 카드가 표시되고, 동의 후 로그인(또는 회원가입)하여 홈 대시보드로 이동합니다. 이후 매장·상품 정보(업종, 메뉴/상품, 타겟 고객, 브랜드 톤앤매너 등)를 등록합니다. 필요 시 매장 대표 이미지를 AI로 생성할 수 있습니다.
2. [1단계 목표 설정] 마케팅 목표(예: 신메뉴 홍보, 재방문 유도, 재고 소진 프로모션, 비인기 메뉴 살리기)와 대상 상품·메뉴를 선택합니다. 타겟 고객과 톤앤매너는 "매장 기본 정보 불러오기" 버튼으로 매장 정보 관리에 등록해 둔 값을 자동으로 불러오거나 새로 입력할 수 있습니다.
3. [2단계 AI 기획] AI가 매장 정보와 목표를 분석해 타겟 고객과 캠페인 방향을 제안합니다. 구독 사용자는 방향을 직접 입력해 AI 기획을 다시 분석받을 수 있습니다.
4. [3-1단계 콘텐츠 설정] 게시할 채널(무료 최대 2개)과 홍보 문구·해시태그 설정을 선택하고, 광고 이미지 생성 여부(토글)를 정합니다.
5. [3-2단계 이미지 설정] 광고 이미지 생성을 켠 경우에만 활성화되며, 이미지 분위기·구성 등 상세 설정을 입력합니다(구독 시 참고 이미지 활용 가능). 토글이 꺼져 있으면 이 단계는 잠금(건너뜀) 처리됩니다.
6. [4단계 시안 비교] AI Creative Studio가 생성한 시안을 비교하고 원하는 시안을 선택합니다(무료·구독 모두 A/B 2종). 시안은 여러 개를 동시에 선택할 수 있습니다. 각 시안은 **'수정하기' 팝업 모달을 통해** 직접 수정(문구·해시태그 편집)하거나 이미지를 다운로드할 수 있고, 구독 사용자는 AI 문구 대안과 AI 이미지 수정(대체)도 이용할 수 있습니다.
7. [5단계 게시] 게시 준비 화면에서 선택한 시안을 모두 확인하고 게시하면, 선택한 시안이 한 번에 게시되고 게시 완료 카드(시안·채널별 게시 결과, 성과·매출 입력 알림 일정, 캠페인 보관함으로 이동)가 표시됩니다. 게시는 모의 구현이 기본이며, 선택 시 실제 채널 API 연동을 시도합니다. 게시된 캠페인은 캠페인 보관함에 저장되며, **이후 보관함의 우측 상세 패널에서 시안 및 채널별 게시 결과를 확인할 수 있습니다.**

### 성과 분석·개선 시나리오

1. 게시 일주일 뒤 시스템이 성과·매출 데이터 입력을 알려줍니다.
2. 사장님이 **캠페인 보관함 우측 상세 패널**이나 성과분석 화면에서 매출 데이터를 업로드합니다(엑셀/CSV 파일, 영수증 사진, 직접 입력 중 선택. 영수증 사진 인식은 모의 처리).
3. 시스템이 상품별·캠페인별·매장 전체 매출을 분석해 캠페인 효과를 보여줍니다.
4. AI 캠페인 개선 방향 화면에서 캠페인 데이터가 충분히 쌓인 사용자에게는 잘된 캠페인(Good)과 아쉬운 캠페인(Bad)을 비교한 개선 방향을, 처음 사용하거나 데이터가 적은 사용자에게는 비교 없이 분석 중심의 제안(잘된 점 / 개선이 필요한 점)을 제공합니다. 프로토타입에서는 데이터가 적은 화면을 기본으로 보여주고, 시연 시 데이터가 많은 화면으로 전환할 수 있습니다.
5. 매출이 낮은 비인기 메뉴에 대한 조언(홍보 조정·메뉴 정리 등)과, 재고가 쌓인 메뉴를 소진하기 위한 프로모션 제안을 함께 제공합니다.
6. 각 제안 항목의 **"이 제안으로 새 캠페인 만들기"** 또는 **"이 프로모션으로 캠페인 만들기"** 버튼을 누르면 캠페인 생성 1단계로 이동하며, 제안에 맞는 목표(예: 재고 소진 프로모션)와 대상 메뉴가 자동으로 선택됩니다. 사용자의 다음 캠페인 참여를 자연스럽게 유도합니다.

### 이용권(무료 체험/구독 전환) 시나리오

1. 신규 가입 사장님에게 월 3회 내외의 캠페인(AI 기획~시안 생성) 이용이 무료로 제공됩니다. 채널 게시 연계는 이 한도 내에서 생성된 캠페인에 대해서만 이루어지므로 별도의 횟수 제한을 두지 않습니다.
2. 무료·유료 구분 기준은 "사용자가 직접 하는 작업은 무료, AI를 추가로 호출하는 작업은 유료(크레딧 차감)"입니다.
3. 월 무료 캠페인 이용 횟수를 모두 사용하면 시스템이 업그레이드 안내를 표시합니다.
4. 사장님이 구독(유료 요금제)으로 전환하면 크레딧 한도 내에서 월 캠페인 이용 횟수가 확대되고, AI 기획 재분석·AI 문구 대안·AI 이미지 수정·참고 이미지 활용 등 AI 기능을 이용할 수 있습니다(결제는 모의 구현).
5. 사장님은 구독 관리 및 크레딧 화면과 이용 현황에서 현재 플랜과 이용량을 확인합니다. 시안 비교·게시 단계 화면에서는 크레딧 차감량·사용량을 별도로 표시하지 않습니다.

|F11|광고 이미지 생성|이미지 생성 AI로 캠페인용 광고 이미지 시안을 생성합니다. 3-1단계 토글이 켜진 경우 3-2단계에서 상세 설정을 입력하며, 구독 시 참고 이미지를 활용할 수 있습니다.|필수|
|F12|실제 SNS·블로그 게시 연동|인스타그램·블로그 등 실제 채널 API와 연동해 게시 또는 예약 게시를 지원합니다.|선택|
|F13|캠페인 보관함|생성·게시된 캠페인을 카드 목록으로 저장·조회하고, **우측 슬라이드 상세 패널**에서 시안**(문구 복사, 이미지 다운로드)**·게시 결과·성과를 확인합니다.|필수|
|F14|AI 이용 한도 관리(무료 체험)|월 캠페인 기획·생성 이용을 3회 내외로 무료 제공하고, 초과 시 업그레이드 안내를 표시합니다. 채널 게시 연계(F08)는 이 한도 내에서 생성된 캠페인에 대해서만 이루어지므로 별도 한도를 두지 않습니다.|필수|
|F15|구독/요금제 관리|구독 관리 및 크레딧 화면에서 플랜·크레딧을 확인하고, 구독 전환 시 월 이용 횟수 확대, AI 기획 재분석·AI 문구 대안·AI 이미지 수정·참고 이미지 활용 등 AI 기능을 제공합니다. 실제 결제 연동 없이 상태값 기반으로 구현합니다.|선택|
|F16|시안 수정 및 이미지 다운로드|각 시안의 **[수정하기] 팝업 모달에서** 문구·해시태그를 직접 수정하고 이미지를 다운로드합니다(무료). 구독 시 AI 문구 대안과 AI 이미지 수정(대체)을 제공합니다(4단계). "내 사진으로 바꾸기"는 복잡도와 사진 미보유 가능성을 고려해 제외합니다.|필수|
|F17|매출 데이터 업로드|매출 데이터 올리기 모달에서 엑셀/CSV 파일, 영수증 사진(OCR, 모의 처리), 직접 입력 3가지 방식으로 매출 데이터를 입력합니다.|필수|
|F18|성과 입력 알림|게시 일주일 뒤 성과·매출 입력을 안내하는 알림을 제공합니다(게시 완료 카드의 알림 타임라인과 연계).|선택|
|F19|AI 캠페인 개선 방향|캠페인 데이터가 충분한 경우 Good/Bad 캠페인 비교로 개선 방향을 제안하고, 데이터가 적은 경우 비교 없이 분석 중심으로 제안합니다. 비인기 메뉴 조언과 재고 소진 프로모션 제안을 포함하며, 각 제안에서 "이 제안으로 새 캠페인 만들기" 등으로 목표·메뉴가 자동 선택된 캠페인 생성을 시작할 수 있습니다.|필수|

> 기능 ID는 이후 요구사항, 화면, 구현 및 테스트에서 동일하게 사용합니다.

### 무료/유료 구분 기준

기본 원칙은 "사용자가 직접 하는 작업은 무료, AI를 추가로 호출하는 작업은 유료(크레딧 차감)"입니다.

|구분|무료|유료(구독·크레딧)|
|---|---|---|
|캠페인 생성|월 3회 내외, 게시 채널 최대 2개|월 이용 횟수 확대(크레딧 한도 내)|
|AI 기획|최초 기획 제안|방향 직접 입력 후 재분석|
|시안 수정|문구·해시태그 직접 수정, 이미지 다운로드|AI 문구 대안, AI 이미지 수정(대체)|
|시안 선택·게시|복수 선택 및 동시 게시|복수 선택 및 동시 게시|
|광고 이미지|기본 생성|참고 이미지 활용|

> 4·5단계 화면에는 크레딧 차감량·사용량을 별도로 표시하지 않습니다. 구독 시 게시 채널 한도 확대 여부는 검토 중입니다.

### 화면 구성

- 사이드바 메뉴: 홈 / 매장 정보 관리 / 캠페인 보관함 / 성과분석 / AI 캠페인 개선 방향 / 구독 관리 및 크레딧
- 사이드바 하단 설정 메뉴: 기존 더보기·설정·로그아웃을 "설정" 하나로 통합하고, 팝오버로 계정 관리 / 크레딧 및 이용 현황 / 로그아웃을 제공
- 캠페인 생성 위자드: 1 목표 설정 → 2 AI 기획 → 3-1 콘텐츠 설정 → 3-2 이미지 설정 → 4 시안 비교 → 5 게시(게시 완료 카드)
- 주요 모달·상세 화면: 이용약관 동의 카드, 계정 관리 카드, AI 매장 대표 이미지 만들기 카드(홈 버튼 또는 매장 정보 관리에서 열림), 다음 단계 확인 팝업, 시안 수정 모달, 게시 준비·게시 완료 카드, 캠페인 보관함 우측 상세 패널, 매출 데이터 올리기 모달, 구독 안내 팝업
- 캠페인 생성 화면: 왼쪽 사이드바 없이 상단 단계 표시줄과 오른쪽 확정 내용 요약 패널(2~4단계)로 구성
- 랜딩 페이지: 히어로, 홍보물 예시 갤러리(쇼케이스), 푸터
- 디자인 기준: 데스크톱 웹(1440×1024), 모든 UI 텍스트 한글

## 6. 개발 범위

### 필수 구현 범위

- 회원가입 및 로그인(이용약관 동의)
- 매장/상품 등록, 마케팅 목표 설정
- AI 캠페인 기획
- AI Creative Studio(텍스트 콘텐츠 시안 생성, 채널 선택 반영)
- 광고 이미지 생성(이미지 생성 AI)
- Creative Gallery(시안 비교·선택), 시안 팝업 모달 직접 수정 및 이미지 다운로드
- 게시 연계(모의 구현), 캠페인 보관함 상세 연동
- 매출 데이터 업로드(엑셀/CSV, 영수증 사진 모의 OCR, 직접 입력) 및 매출 성과 분석
- AI 캠페인 개선 방향(Good/Bad 비교, 비인기 메뉴 조언, 재고 소진 프로모션 제안)
- 대시보드
- AI 이용 한도 관리(무료 체험 횟수 제한 및 초과 시 업그레이드 안내)
- 데이터베이스 연동 및 서버 배포

### 선택 구현 범위

- 실제 SNS·블로그 API 연동(게시 연계 기능 확장)
- 성과 입력 알림(게시 일주일 뒤)
- 유료 구독/요금제 관리 및 구독 전용 AI 기능(AI 문구 대안·AI 이미지 수정 등, 모의 결제, 상태값 기반)
- 영수증 사진 실제 OCR 인식(기본은 모의 처리)

### 제외 범위

- 고객 리뷰 수집·응대·분석 기능(본 프로젝트 범위 밖)
- POS 시스템 실연동(매출 데이터는 사용자가 파일·영수증·직접 입력으로 제공)
- 실시간 채팅
- 모바일 네이티브 앱(웹 반응형으로 대응)
- 실제 PG(결제대행사) 연동을 통한 금전 이체(요금제 전환은 상태값 기반 모의 구현으로 대체)

## 10. 결과물 및 성공 기준

### 예상 결과물

- 소상공인용 웹 정보시스템(BizGent)
- USE-CASE 다이어그램, 화면설계서, ERD
- Spring Boot 기반 소스코드 및 GitHub 저장소
- 테스트 결과, 배포 시스템 및 사용자 매뉴얼
- 최종 발표자료 및 개인 포트폴리오

### 성공 기준

- 사장님이 매장·상품 정보와 마케팅 목표를 입력하면 AI가 타겟 고객과 캠페인 방향을 제안합니다.
- AI Creative Studio가 생성한 여러 콘텐츠 시안(문구·광고 이미지)을 Creative Gallery에서 비교·선택하고, 직접 수정하거나 이미지를 다운로드할 수 있습니다.
- 선택한 채널에 맞는 콘텐츠가 생성되고, 게시 상태가 시스템에 반영되어 캠페인 보관함에서 확인할 수 있습니다.
- 매출 데이터(파일 업로드·영수증 사진·직접 입력)를 입력하면 상품·캠페인·매장 단위의 성과 분석을 확인할 수 있습니다.
- 캠페인 데이터가 쌓이면 Good/Bad 캠페인 비교를 바탕으로 한 개선 방향을, 데이터가 적을 때는 분석 중심의 제안을 확인할 수 있습니다.
- 무료 이용 한도(월 캠페인 기획·생성 3회 내외)를 초과하면 업그레이드 안내가 표시되고, 구독 전환 후 확대된 혜택(이용 횟수 확대, AI 기획 재분석, AI 문구 대안·AI 이미지 수정)을 정상적으로 이용할 수 있습니다.
- 실제 소상공인 또는 잠재 사용자 3명 이상을 대상으로 사용성 테스트를 진행하고 피드백을 반영합니다.
- 배포된 시스템에서 매장 등록 → 캠페인 기획 → 콘텐츠 생성 → 선택 → 게시 → 매출 입력 → 성과 분석 → 개선 방향 확인으로 이어지는 핵심 시나리오를 처음부터 끝까지 시연할 수 있습니다.
