# BizGent

**소상공인을 위한 AI 디지털 마케팅 에이전트**

> 정보시스템 프로젝트 캡스톤 디자인 | 사계절 팀  
> 분석·설계 문서를 기반으로 실제 시스템 구현을 준비하는 프로젝트입니다.

## 1. 프로젝트 소개

BizGent는 소상공인이 **매장 정보와 마케팅 목표만 입력**하면, AI가 타겟 고객 분석과 캠페인 기획, 콘텐츠 시안(이미지·문구) 생성, 채널 게시, 매출 기반 성과 분석, 개선 방향 제안까지 지원하는 웹 기반 AI 디지털 마케팅 에이전트입니다.

소상공인은 전문 마케팅 인력이 부족해 SNS·블로그 홍보 기획, 콘텐츠 제작, 성과 추적에 어려움을 겪고 있습니다. BizGent는 이 과정을 하나의 서비스로 일원화하여 소상공인의 자립적 마케팅을 지원합니다.

**핵심 차별점은 기획부터 개선까지 이어지는 순환 흐름입니다.** 캠페인을 기획하고 시안을 만들어 게시하는 데서 끝나지 않고, 사장님이 입력한 매출 데이터를 바탕으로 캠페인 성과를 분석하고 다음 캠페인의 개선 방향을 제안합니다. 제안 카드에서 바로 새 캠페인을 만들 수 있습니다.

> 실제 SNS 게시 연동, 영수증 OCR, 구독 결제는 **모의 처리를 기본**으로 하며 일정에 따라 확장합니다. 실제 결제(PG)는 개발 범위에서 제외합니다.

## 2. 프로젝트 목표

- 매장·상품 정보와 마케팅 목표를 바탕으로 AI가 타겟 고객과 캠페인 방향을 제안
- 채널별 맞춤 문구와 광고 이미지 시안을 생성하고, 비교·수정 후 게시
- 매출 데이터(엑셀/CSV, 영수증 사진, 직접 입력)를 바탕으로 캠페인·상품·매장 단위 성과 시각화
- 성과 분석에 따른 개선 방향, 비인기 메뉴 조언, 재고 소진 프로모션 제안
- 월 무료 이용 한도와 구독 전환 안내를 통한 AI 이용 관리

## 3. 핵심 기능

| 구분 | 주요 기능 | 관련 기능 ID |
| --- | --- | --- |
| **매장·계정** | 회원가입/로그인, 이용약관 동의, 매장·상품·톤앤매너 등록, AI 대표 이미지 생성 | F01·F02 |
| **AI 캠페인 기획** | 마케팅 목표·대상 메뉴 선택, 타겟 고객 및 캠페인 방향 제안, 직접 입력 재분석 | F03·F04 |
| **콘텐츠 생성** | 게시 채널 선택, 채널별 맞춤 문구 생성, 광고 이미지 스타일·비율 설정 및 생성 | F05·F07·F11 |
| **시안 비교·수정** | 시안 비교 및 선택, 문구·해시태그 직접 수정, 이미지 다운로드 | F06·F16 |
| 게시·보관함 | 시안 게시 및 완료 카드, 캠페인 보관함 및 상세 패널 | F08·F13 |
| 성과 분석 | 매출 데이터 업로드, 상품·캠페인·매장 단위 성과 분석 및 시각화 | F17·F09 |
| 개선 방향 | Good/Bad 비교 분석, 메뉴 조언, 새 캠페인 바로 만들기 | F19 |
| 대시보드·이용 한도 | 매장 현황과 최근 캠페인 확인, 월 3회 무료 제공 및 초과 시 구독 안내 | F10·F14 |
| 선택 구현 | 실제 SNS API 연동, 구독/요금제 관리(모의), 게시 1주일 후 성과 입력 알림 | F12·F15·F18 |

**서비스 흐름:** 매장 등록 → 목표 설정 → AI 기획 → 콘텐츠·이미지 설정 → 시안 비교·수정 → 게시 → 매출 데이터 입력 → 성과 분석 → AI 개선 방향 → 새 캠페인 생성

※ 캠페인 생성 중에는 이전 단계를 수정할 수 없으며, 다음 단계로 이동할 때 확인 팝업이 표시됩니다.
